# Render lab control reference

Generated by `renderlab/gen-controls.py` from `RenderLabControlsDump` (ProofRegistry + the recipe's own JSON encoding). Do not edit by hand. Use the **recipe path** as a key in a manifest `recipe` patch or as a sweep `path`. Range is the proof lane's declared travel; the app may accept values beyond it (the patch reports any value the recipe decoder changed under `recipeAdjusted`).

Defaults are `Recipe()` (base `blank`). Base `imported` (the default) is what the app gives a new RAW: the same, plus ISO-dependent noise reduction (table at the end).
