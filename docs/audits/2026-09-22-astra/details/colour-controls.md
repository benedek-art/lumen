# Tone and color control inventory

Audited main: `99c37272b42c211a04262ceb98cfb39355d1ab99`. This is a 154-row, source-traced census of the tone/color area. Rows include non-slider handles and flags; dynamic Point Color swatches share one row per control role, not eight duplicate sets. It is not the same count as the repository's 135 proof-registry entries. A source-audited status is not a promise that every image and combination was tested. Per-control model paths and full evidence are also in `control-inventory.json`.

Scope excludes film/effects, spatial detail/presence, mask-only controls, geometry and export controls, which other audit areas own. Newer branch renames mixer Green/Blue to Mint/Azure, fixes main Basic Contrast and grading-wheel paint, and makes display Contrast logarithmic; see the report for branch distinctions.
