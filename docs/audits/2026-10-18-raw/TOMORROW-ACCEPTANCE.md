## Input and edit integrity

- Fast slider and wheel drags must commit the final mouse-up position, including when the last movement event is coalesced. Test release outside the control, double-click reset, undo/redo and rapid successive gestures.
- Open numeric entry on a rounded value such as1.234 shown as1; submitting unchanged text must preserve the precise value and create no edit. Test explicit typed changes, Escape/Return/focus loss, photo/batch/mask/component/swatch/mixer-band retargeting and All bands.
- Test off-grid values beyond soft slider limits: outward keyboard/wheel/accessibility nudges hold exactly; inward nudges work. Confirm intended saved values and visible marks across undo/reopen.
- During immediate selection changes, unavailable white-balance dimensions must not write fabricated5500K/0 values. Check temp-only and tint-only overrides and mask Kelvin activation. Shift and Kelvin are separate correction modes; an edited-mode switch can still change the picture. No lossless conversion was implemented.

## Preservation, masks and delivery

- Use disposable copies for external-XMP conflict, missing brush/heal dependency, failed write, disconnect/reconnect and restart exercises. Confirm the latest catalog edit, exact retained external document and portable painting/debt recovery. Future/corrupt formats must remain intact and unavailable where their edit cannot be represented.
- Verify named snapshots, gesture history, selection changes and a real new-process restart. Cloud AppState reconstruction and generated fixtures do not prove every native lifecycle.
- Inspect tiny brush endpoints, feathered edges, heal-source positioning and mask coverage at native resolution, including rotated/reflected/cropped photos. Geometry oracle passes do not establish subjective edge/texture quality.
- Compare preview and actual JPEG/TIFF16/HDR delivery under matching geometry, output color management and sharpening. Check highlights, skin, saturated edges, fine foliage, B&W and local edits before/after reopen. Keep calibrated target/chart evidence distinct from pleasing appearance.
- Exercise real removable/full/disconnected volumes and independent backup hardware on disposable test data. Synthetic filesystem failure injection does not qualify physical-drive behavior.

## Denoise and responsiveness, separately

- Classic is VST/wavelets; AI is Apple's RAW denoise stand-in, with no bundled learned model. Assess luma/chroma/detail/hot-pixel behavior on each camera across ISO, particularly GX85 high ISO. Both cameras currently use generic full-frame ISO noise seeds; synthetic MSE improvement is not camera calibration.
- Judge noise reduction against retained fine texture/color and spatial artifacts, not noise variance alone. Zero-strength identity, mathematical response and subjective quality are separate claims.
- Measure native first-frame/sample latency, warmed slider-to-completed-frame latency and memory on the owner's hardware. Report actual completed frames and timing conditions. Cloud shared-process timings and process-cold command RSS do not establish cold-disk or GPU memory bounds.

Acceptance does not imply every feature or aesthetic quality is certified. Preserve unresolved failures and blocked checks alongside passes.
