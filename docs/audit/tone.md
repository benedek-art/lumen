- **TONE-12 — "Highlights can never push past display white — implemented as geometry" is stale; the property now rests on the transform's clamp.** FAKE (caption). - **TONE-13 — The LrC-calibration claim has no corpus, no goldens, no test.** UNPROVEN. docs/04 §Six-Slider "Calibration" claims ±100 ≈ ∓2 EV "tuned against LrC 15.5 renders of the golden corpus". - **TONE-14 — No test pins the six sliders' end-to-end authority in code values — exactly the regression class that shipped twice.** UNPROVEN. docs/19 measured Blacks at 2.9/255 while every structural test passed, then 23.1 after the fix. - **TONE-15 — The GPU tone stage is a 32³ resample of the 1024-sample gain LUT; no golden moves Highlights/Shadows/Whites/Blacks through the shipping graph.** UNPROVEN. - **TONE-16 — Slider behaviour on rendered (JPEG/HEIC/TIFF) files unmeasured.** UNPROVEN. White anchor +5 EV (ToneEngine.swift:88) vs a JPEG's max ≈ +2.47 EV above mid-grey; Highlights' shelf reaches ~0.5 weight and Whites' shelf mostly windows values the file cannot contain.
