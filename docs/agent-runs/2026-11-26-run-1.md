# Run 1: 2026-11-25 evening to 2026-11-26 06:00 UTC

Status: IN PROGRESS. This log is updated at the end of the run; anything marked "pending" was still running when it was last written.

## Why this run happened

The owner reported four problems: trackpad zoom glitching and confined to the image borders; the mask overlay's red never going away (wanted: Lightroom's behaviour); sliders not updating the picture until the drag ends; and, generally, needing to trust every control before editing real photos. Earlier rounds had "fixed" all of these from code reading. Nobody had ever run the app in the fix loop, so this run built the tools to do that first.

## What was built

- **Driver** (`driver/`, `Sources/LumenApp/Driver/`): real-app automation on hosted macOS runners with HID input. Milestone 1 report: all input verbs work (scroll and pinch fully real through the HID tap; an in-process mode is approximated), screenshots, full state dump by reflection, frame timeline, a pixel witness for geometry, a main-thread stall sampler with symbolized stacks, about 73 s per warm run.
- **Render lab** (`renderlab/`): manifest-driven renders through the real export and viewer paths on macOS; a Linux reference lane on charts and decoded RAW plates that agrees with shipping within 0.2 to 0.4 code values for tone, white balance, saturation, film stocks and vignette (up to 3.9 for clarity plus sharpening).
- **Area map** (`driver/AREAS.md`): 30 areas, about 500 controls, about 226 journeys.
- **CI trimming** (integration fd256da6): tester and request branches start no CI; fix branches run test-fast only.

## Known open items not yet assigned

- Saturation +100 darkens saturated colours about 9% in linear luminance (both render paths agree). Possibly intentional (H-K-aware model). Taste call for the owner.
- Double-click to 1:1 lands the clicked point 1.25 to 1.55 pt from the pointer (target 1 px); `Z` is 0.72 pt.
- Sharp render after a zoom still takes 0.6 to 0.9 s on the runner; the stretched fit frame is soft until then.
- Driver: most buttons and toggles have no named target (sliders and mask controls do); sheets and popovers are unreachable; OCR on the VM misreads small type; one app instance per runner.
- Render lab cannot yet reach masks, heal, Upright, soft proof, HDR/gain-map export, or formats other than 8-bit sRGB PNG.
- Decode-keyed controls (capture sharpening, AI denoise amount, lens profile) re-decode the RAW per drag event; mitigated with adaptive half-size drafts, not removed.
