# R2 — Capture One (current release)

Read `briefs/w1-common.md` first. Output: `docs/audit-2026-09/w1/r2-captureone.md`.

Capture One is the colour-editor and layers benchmark, and the UI the owner's target
("modern pro") most resembles. `docs/03` covers it briefly; go deep.

## Must cover
1. **Color Editor** — Basic / Advanced / Skin Tone tabs: how a colour is picked, the
   hue/saturation/lightness range wedges, smoothness, uniformity (skin), "view selected
   color range", how many ranges, how it differs from an 8-band HSL mixer.
2. **Color Balance** (3-way + master) — wheel semantics, what Lightness does per zone,
   the shadow/mid/high pivots.
3. **Layers & masks** — the Layers tool, Luma Range (its dialog: range, falloff,
   radius, sensitivity), Magic Brush, AI masks (Subject/Background), gradient and
   radial masks' on-canvas handles (rotate, feather ring, invert), mask refinement
   (feather, refine edge), per-layer opacity, "fill mask", copy mask between layers.
4. **Styles & presets** — layered styles, style opacity, normalisation, brushing a style.
5. **Speed Edit** — which keys, how the drag works, the on-screen readout.
6. **Sliders** — precision drag, modifier keys, value entry, reset gestures.
7. **Tone** — Exposure/Contrast/Brightness/Saturation, HDR tool (highlight/shadow/
   white/black), Levels, Curve (RGB/Luma/per-channel), Clarity methods (Natural/Punch/
   Neutral/Classic), Structure, Dehaze.
8. **Sharpening & NR** — diffraction correction, Sharpening (amount/radius/threshold/
   halo suppression), Noise Reduction (luminance/details/color/single-pixel), the
   output sharpening in Process Recipes.
9. **Catalog/sessions & culling** — sessions vs catalog, Cull mode (face/eye focus,
   group by similarity), rating/tag keys, the filter panel with live counts, Smart
   Albums.
10. **Process recipes** (export) — recipe list, proofing from the recipe, watermark,
    metadata, ICC, output sharpening, "scale" modes.
11. **Viewer** — zoom grammar, before/after, focus mask, exposure warnings, the
    Lights-out / full-screen viewing modes, the background colour control.
12. **UI system** — the panel density, type sizes, how tool tabs are organised and
    customised, what makes it read as "modern pro" (describe concretely: surfaces,
    edges, spacing, iconography, hover/focus behaviour).
