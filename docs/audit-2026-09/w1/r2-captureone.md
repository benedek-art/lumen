# R2 — Capture One 16.8.x (current release), deep teardown

Scope: the twelve "must cover" items in `briefs/w1-r2-captureone.md`, filed into the thirteen
common areas A–M. Version ground truth is 16.8.4 (docs/17 §C). Web reach was uneven: `WebSearch`
worked; `WebFetch` was egress-blocked on support.captureone.com, captureone.com, alexonraw.com and
imagealchemist.net, so no page was read in full — every `[search: …]` tag is a search-result
summary of that page, not the page. `[knowledge]` claims are unverified this session and are
repeated under "Could not verify" when an auditor's verdict would hinge on them.

"Lumen would need" lines are from `grep` over `Sources/` (files named), not from the specs.

## I · Pipeline & performance

Mostly not applicable to a feature teardown. Two mechanisms auditors may want: (1) Enhanced Denoise's **once-per-raw background render cached and shared across variants** (E above); (2) **Process queue**: a Batch tab lists queued exports, reorderable, pausable, running in the background while editing continues [docs/03 §1.9]. Lumen: `ExportSheet` is a one-shot multi-recipe run — check whether a queue/pause exists (`grep -i "queue\|pause" ExportSheet.swift AppStateActions.swift`).

## New relative to docs/02–03

- Advanced Color Editor allows **up to 30 colour-range corrections per image**; the pick wedge has **outer handles for range and an inner handle for the hue point**, drawn as a wireframe with direction arrows. [search]
- "View selected color range" renders everything outside the slice **in black-and-white** (not dimmed). [search]
- Skin Tone Uniformity is **three 0→100 sliders (hue, saturation, lightness)** in a separate "Uniformity" group from the "Amount" HSL group. [search]
- Color Balance zone crossfade rule stated officially: **Shadow wheel never affects highlights, only the lowest midtones**. [search]
- Luma Range dialog anatomy: **two upper handles = Range, two lower handles = Falloff (per end), plus Radius (px) and Sensitivity (edge/contrast detection added to Radius), Invert Range**. [search]
- Feather Mask radius **default 10, max 100**; Refine Mask radius **default 10, max 300 px**; Refine *expands* the mask and modulates opacity by contrast. [search]
- Radial mask grammar: **⌥⇧ = 1:1 circle from corner; four handles on the central line reshape; hover central line to rotate; ⇧-drag inner/outer ring adjusts feather with centre locked; drag the outer ring through the centre to invert**. Linear: **⌥ moves one end line alone**. [search]
- Magic Brush controls are **Tolerance + Refine Edge** (0 = hard). [search]
- Style strength on a layer is the **layer Opacity** — there is no separate style-amount slider; Style Brushes auto-create the layer on first stroke. [search]
- Normalize tool (Pick/Apply Normalize Color, WB and/or Exposure) is the actual "normalisation" feature; it is unrelated to styles. [search]
- Speed Edit default map: **Q/W/E/R = Exposure tool, A/S/D/F = HDR tool**; drag works on **both axes** (L/R and up/down), plus scroll and arrows. [search]
- Slider contract: **⇧+arrow = 10×**, scroll-wheel needs a preference, ⇧+scroll = larger steps, **no fine-drag modifier exists** (community asks for one); **⌥-click on a tool's reset arrow = momentary before**. [search]
- Clarity method characterisation from the official page **contradicts docs/03 §1.6** (Classic = *mildest* local contrast and best highlight preservation, not "halo-prone large-radius"). [search]
- Enhanced Denoise (16.8) = **one Impact slider**, background denoised-raw generated once and shared across variants, still beta in May 2026. [search]
- Cull window: **similarity slider default 75 %**, ↑/↓ within group, ←/→ across groups, G toggles grid/viewer; Face Focus at **50/100/200 %** with **Limit to Eye / Face**. [search]
- Assisted Review (16.8) works by **adding filterable tags** (closed eyes, mis-focus, exposure), not by ranking. [search]
- Process Recipe **Never Upscale applies to every scale mode except Fixed**; Recipe Proofing simulates scaling + output sharpening. [search]
- Viewer: **no Lights-Out mode** (community-confirmed); background colour via **right-click on empty Viewer**; zoom ladder 25/33/50/67/100/200/300/400…1600 with "." and "," keys; Before/After has **Full View vs Split View Slider**, ⇧Y, and the before state **keeps crop/geometry**. [search]
- Focus Mask **threshold default 250**; highlight warning default 250; **shadow warning off by default**. [search]
- Tool Tabs: 15.3 large-icon reorganisation, **Icons Only (compact)**, **Default (Legacy)** workspace, pinned vs scrollable tool areas, floating tools, custom tool tabs. [search]
