## Findings

### C1-01 — GPU halation gate is a pedestal that never meets the reference's smoothstep
severity: S2
confidence: measured
class: defect
size: S
evidence: `Kernels.swift:434-436` `vec3 e = max(image.rgb - vec3(threshold), vec3(0.0)) * boost;` with `threshold = clip·2^(−4/2) = 0.25` and `boost = 2^0.3` (`FilmLab.swift:569-576`). Reference `FilmLab.swift:547-549` `t = smoothstep(−4, 0, ev); out = t·e·2^(0.3t)`. Computed ratio GPU/reference by scene value: E=0.25 → 0.000, 0.354 → 0.458, 0.5 → 0.612, 1.0 → 0.750, 2.0 → 0.875, 4.0 → 0.937, 8.0 → 0.969. The golden's block is E=4.0 (`KernelGoldenTests.swift:845-848`), so it reads the 6% corner; its mass bound is 30% (`:910-914`). The comment at `FilmLab.swift:562-566` — "matched at the reference ramp's half-power point" — is false: for E > 0.25 the GPU curve is below the reference at every value and the two never cross.
how the owner sees it: A bright but unclipped sky (0.5–1.0 scene) glows 25–40% less on screen and in export than the f64 reference the goldens are written against; a sky at −2 EV under the clip glows on the reference and not at all in the app. Preview and reference disagree most where real photographs keep their highlights.
fix: `Kernels.swift` `lumenHighlightEnergy`: `float ev = log2(max(e,1e-6)/clip); float t = smoothstep(-4.0, 0.0, ev); e = t*e*exp2(0.3*t);` — one `log2` per pixel at S13, as R7 C.1.5 specifies. Pass `clipLevel` and `protectEV`/`boostRange` instead of `threshold`/`boost`; delete `threshold`/`boost` from `HalationProfile`. Test: `testHalationGlowIsAsWideAsTheProfileSays` mass tolerance 30% → 3%, and a second block at E = 0.5 where the pedestal reads 0.61 of the reference — with the pedestal substituted back, both go red.

### C1-02 — Strength does not scale halation or grain: 0→1 still switches the whole glow and the whole grain field on
severity: S2
confidence: traced
class: defect
size: S
evidence: `FilmLab.swift:1399-1405` `halationAmount` returns `recipe.halation/100` with no reference to `strength`; `:1410-1413` `grainAmount` returns `grain.amount × densityScale` for any non-nil `solved`; `:1322` builds `solved` whenever `blend > 0`; `RenderPlan.swift:252` builds the chain at `film.amount > 0`. Substitute the unscaled getters back → both red.

### C1-06 — Push/pull is contrast-only; R7's "one-line deltas in `build`" is half right — the exposure loss cannot live there
